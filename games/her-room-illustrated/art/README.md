# 「她的房间」插画版 · 美术可行性探针（T-11695）

大肥鱼插画房间的小样：1 张角色设定图、空房间底版（台灯关 / 开）、3 个状态（趴在床上看手机、背对镜头坐在桌前用电脑、睡觉）× 台灯关 / 开两版、屏幕四角坐标、验收对照图。
流程按方案 T-11682（`docs/illustrated-room-design.md` §11）执行：GPT Image 编辑模式，每张状态图都带「空房间底版 + 冻结的设定图」作参考，提示词里逐字复制同一段角色描述。

这是探针目录，不是游戏包：没有 `pack/`、`store.json`，`games/pixel-room`（原 her-room 像素版）一行没动。正式游戏包由后续任务 D 建，可以直接复用这里的流程和脚本。

## 文件

| 路径 | 内容 |
| --- | --- |
| `prompts.json` | 全部提示词：`character`（固定角色描述）、`style`、`room`，以及每张图的 `prompt` / `refs` / `size`。`round: 2` 是第 2 轮重出的，`round1/*` 是第 1 轮留档 |
| `generate.py` | 出图：`refs` 里的本地图先 `lh file upload` 拿 URL，再 `lh generate image -m gpt-image-2.5-sunburst -p lobehub --param imageUrls=[…] --param size=… --param quality=high`；一次一张、间隔 20 秒 |
| `raw/` | 模型原图（2048×1152，设定图 2048×2048），已转无损 WebP。`raw/round1/` 是第 1 轮被替换下来的看手机 / 睡觉 |
| `ref/` | 参考：录屏截帧 ref-8 / ref-52 / 16 帧总览、角色裁图、像素桌宠的大肥鱼 |
| `post.py` → `out/` | 缩到 1920×1080 世界坐标、ECC 仿射对齐到底版、静止区域差异和光照变化数值（`out/post-report.json`）、导出 WebP q88 |
| `screens.py` → `screens.json`、`preview/screens-*.jpg` | 屏幕四角（人工标注）+ 叠框核对图 |
| `sheets.py` → `preview/{compare,character,lighting,layout}.jpg` | 验收对照图 |

重跑：`python3 generate.py [名字…]`（已有的跳过，`--force` 重出），然后 `python3 post.py && python3 screens.py && python3 sheets.py`（需要 pillow、numpy、opencv-python-headless）。

## 出图顺序

1. `dafeiyu-sheet`：文生图 + 参考图（ref-8 / ref-52 裁出的大肥鱼、像素桌宠大肥鱼），三视图 + 4 个表情（睁眼、闭眼、犯懒、笑）。**冻结**，之后每张状态图都带它。
2. `dafeiyu-base-off`：参考 ref-8 / ref-52 的镜头和布局，出没有人的房间，台灯关。
3. `dafeiyu-base-lit`：编辑 base-off，只把台灯打开。
4. `dafeiyu-<状态>-off`：编辑 base-off + 设定图，「把这个角色放进房间：<姿势>，房间、镜头、光照完全不变」。
5. `dafeiyu-<状态>-lit`：编辑该状态的 off 图 + base-lit，「按第二张图的台灯光照重新打光，其它不变」。

### 第 1 轮 → 第 2 轮（调整了什么）

| 第 1 轮问题 | 调整后的流程 | 第 2 轮结果 |
| --- | --- | --- |
| 看手机：手机竖着举在脸前，**屏幕朝她、背面朝镜头**，画面里没有可贴内容的屏幕 | 在第 1 轮 off 图上再编辑一次：只改手和手机，手机屏幕朝上平放在她胸前，一根手指点着屏幕；再用新 off 图 + base-lit 重新打光 | 屏幕整块朝上可见，脸、发型、服装、尾巴保持第 1 轮的样子 |
| 睡觉：笔记本合着、没有手机，**没有屏幕**可标四角 | 在第 1 轮 off 图上编辑：只加一部屏幕朝上、锁屏微亮的手机放在枕边；再重新打光 | 枕边手机锁屏可见，角色不变 |

角色在第 1 轮就已经一致（见 `preview/character.jpg` 最后一格），两次重出都是为了屏幕，不是为了角色。

| 状态 | 屏幕 | 内容（方案 §7） | 四角 | 遮挡 |
| --- | --- | --- | --- | --- |

| sleep | 手机 | lock 锁屏 | (330,766) (361,752) (414,800) (382,816) | 无 |

phone / sleep 状态里笔记本是合着的，没有屏幕可贴。自动检测（高亮连通块）只能框到文档页或被手指截断，所以改为人工标注，再用 `preview/screens-*.jpg` 在 off 和 lit 两版上叠框核对，两版都贴住屏幕玻璃。

## 自查结论

### 画风与氛围

| 项 | 结论 | 说明 |
| --- | --- | --- |
| 日系手绘插画，不是像素画 | 符合 | 线稿 + 赛璐璐 / 厚涂上色，1920×1080 下没有像素块 |
| 斜上方俯视、有纵深 | 符合 | 约 45° 从房间一角往下看，床面、桌面、椅面的顶面都可见，墙角透视收敛 |
| 深夜蓝色月光 | 符合 | 全屋冷蓝，台灯关时只有窗外月光 / 城市光 |
| 窗外下雨、城市光斑 | 符合 | 玻璃上有雨丝和水珠，窗外楼群虚化成光斑 |
| 生活感物件 | 符合 | 揉皱的被子（床尾一堆）、成摞的书（桌上两摞 + 书架）、搭着衣服的椅子、笔记本电脑、散落的纸、摊开的本子和笔、马克杯、药瓶、墙上的便签、垃圾桶 |
| 和参考帧比 | 部分符合 | 布局（左上横窗、斜放的单人床、右侧书桌和台灯、右下转椅）和参考一致；参考的开灯画面整屋更暖、高光泛光更强（录屏是对着屏幕翻拍的，带摩尔纹和过曝），小样开灯后床一侧仍偏蓝。整屋暖度可以在引擎的 `lampGlow` 加色层上调 |

### 角色一致性（对照 `preview/character.jpg`）

| 状态 | 脸 | 发型 | 服装 | 头饰 | 鲸鱼尾 |
| --- | --- | --- | --- | --- | --- |
| 设定图 vs 参考录屏 | 符合：大圆蓝眼、小脸、Q 版约 3 头身 | 符合：深蓝长卷发、一根呆毛、齐刘海 | 符合：深蓝女仆裙、白领 + 深蓝蝴蝶结、白袖口、白荷叶边围裙 | 符合：白色荷叶边女仆头饰 + 小蝴蝶结，两侧鲸鳍耳 | 符合：深蓝鲸鱼尾、浅色腹面 |
| 趴在床上看手机 | 符合：同样的大圆蓝眼和小脸，低头看手机 | 符合：长卷发铺在床上、呆毛、齐刘海 | 符合：深蓝裙、白领蝴蝶结、白袖口、荷叶边裙摆、白袜、深蓝玛丽珍鞋 | 符合 | 符合：在身后翘起 |
| 背对镜头用电脑 | 不适用：按设计背对镜头，看不到脸 | 符合：背影长发、呆毛；比设定图稍直一点，卷度弱 | 符合：背后白色围裙大蝴蝶结（对应设定图背视图）、深蓝裙、荷叶边 | 符合：从背后看到荷叶边头饰和鳍状耳 | 符合：从椅子边垂下 |
| 睡觉 | 符合：对应设定图「闭眼」表情 | 符合：长发散在枕头上、呆毛、齐刘海 | 符合（大部分在被子里）：露出的袖口、领口荷叶边一致 | 符合：睡觉也戴着 | 符合：从被子边露出 |

各状态之间只有光照造成的颜色差（月光下整体偏蓝、台灯开时头发受暖光），没有换发色、换衣服或少头饰 / 尾巴的情况。

### 房间布局一致性（对照 `preview/layout.jpg`）

| 项 | 结论 | 说明 |
| --- | --- | --- |
| 窗户、窗帘、床、枕头、书桌、台灯、书架、便签、转椅、垃圾桶的位置 | 符合 | 四张图叠同一组参考线，窗框、窗台、书桌左边、台灯、椅子都落在同一位置；ECC 对齐没有可修正的位移 |
| 状态相关的变化 | 符合（按设计） | 用电脑：笔记本打开、椅子推到桌前、外套挪到椅背；睡觉：被子盖在她身上；看手机 / 睡觉：床上多一部手机 |
| 像素级静止区域差 < 4/255（方案 §11.4） | 不符 | 窗户区 4.7–7.5、墙面 3.7–6.8。肉眼看不出，但做交叉淡化时窗户里的雨丝会轻微「换一遍」 |

**像素级不符的处理（交给任务 D，不阻塞本探针）**：雨和光斑在引擎里本来就是窗户遮罩里的叠加层（方案 §4.2），把各状态图里窗户多边形内的像素统一换成底版的窗户；其它静止区域用「和底版差异大的区域 = 角色 + 光照」做遮罩，遮罩外统一取底版像素（`post.py` 里加一步合成）。这样静止部分逐像素相同，交叉淡化时只有角色在变。

## 结论

方案的生图流程可行：设定图冻结 + 底版编辑能让 3 个状态里的大肥鱼保持同一张脸、发型和服装，房间布局在所有状态里对齐，台灯开 / 关两版光照差别明显，3 个状态都有可标四角的屏幕。经过 2 轮（第 2 轮为了屏幕可见），3 个状态一致，没有卡住的问题。

给任务 D 的建议：每个新状态按「base-off + 设定图 → off；off + base-lit → lit」出；需要屏幕的姿势在提示词里写明「屏幕朝上 / 朝镜头可见」；后处理加窗户区和静止区域的底版合成。
